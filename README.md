# MAFERTASAN

Sitio estático preparado para Vercel; no requiere instalación ni compilación.

La identidad visual usa blanco y tonos lilas y morados, con detalles suaves de acento.

Todo el contenido principal vive en `index.html`. Las pestañas “Punto físico”, “Métodos de pago” y “CEO” muestran su información dentro del mismo sitio. La página CEO presenta a Mayerli Guzmán.

Al subir una actualización a la rama `main` del repositorio conectado, Vercel iniciará un nuevo despliegue automáticamente.

La carpeta `assets` contiene la imagen principal, las seis imágenes optimizadas para las categorías de servicios y el retrato de Mayerli.

El formulario abre WhatsApp con la solicitud preparada; la persona revisa el mensaje y lo envía desde WhatsApp. La política de privacidad y los términos todavía necesitan revisión y adaptación al negocio.
